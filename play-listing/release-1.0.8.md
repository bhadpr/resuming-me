# Release 1.0.8 (version code 11)

Signed bundle: `android/app/build/outputs/bundle/release/app-release.aab`

Version code 10 is already on Play. This build is the same app as 1.0.7: Steps only, no Distance.

## Release notes (en-IN, max 500)

One daily list for habits, vitals and reminders. Missed a day? Just resume.

• Walking, pranayam, prayer and more. Start with a few minutes.
• Blood pressure, weight, water and steps.
• Bills, visits, birthdays and festivals. Yearly ones come back on their own.
• Try it without an account. Sign in with Google to keep what you set up.
• English, Hindi, Gujarati, Marathi, Telugu, Tamil and Bengali.

## Play Console, in this order

1. **App content → Health Connect.** Remove Distance. Keep Steps (`READ_STEPS`) only. Save the form.
2. **Closed testing → Create new release.** Upload this AAB and paste the release notes. Do not upload version code 10 again.
3. Send it for review.

Data safety does not change. Step counts stay on the phone.
