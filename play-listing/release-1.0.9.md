# Release 1.0.9 (version code 12)

Closed testing only. Production stays on 1.0.8 (version code 11).

Signed bundle: `android/app/build/outputs/bundle/release/app-release.aab`

This build adds reminder lists: one link, up to 20 reminders, one optional picture. It also opens `resuming.me/c/…` inside the app.

## Release notes (en-IN, max 500)

One daily list for habits, vitals and reminders. Missed a day? Just resume.

• Walking, pranayam, prayer and more. Start with a few minutes.
• Blood pressure, weight, water and steps.
• Bills, visits, birthdays and festivals. Yearly ones come back on their own.
• Try it without an account. Sign in with Google to keep what you set up.
• English, Hindi, Gujarati, Marathi, Telugu, Tamil and Bengali.

## Play Console

1. **Closed testing → Create new release.** Upload this AAB and paste the release notes. Do not upload version code 11 again.
2. Send it for review. Leave Production on 1.0.8.
3. After the test is approved, install it from the closed-testing link on a phone that is in the tester list.

No new Android permissions. Health Connect stays Steps only. Data safety does not change.
